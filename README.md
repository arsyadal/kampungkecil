# Kampung Kecil Cikarang Landing Page

A premium, modern, and responsive landing page for the **Kampung Kecil Cikarang** restaurant. Built with React and Vanilla CSS, this project showcases the restaurant's traditional Indonesian atmosphere with a high-end visual aesthetic.

## 🌟 Features

-   **Stunning Hero Section**: High-quality AI-generated imagery of the restaurant with a cinematic feel.
-   **Responsive Navigation**: Modern glassmorphism navbar that adapts smoothly to mobile devices.
-   **Menu Showcase**: Visual grid featuring signature dishes like *Cumi Kremes*, *Bebek Sambel Matah*, and *Nasi Liwet*.
-   **Gallery Section**: Curated photos highlighting the unique 'saung' (hut) dining experience.
-   **Integrated Contact**: Location details with embedded Google Maps and a direct WhatsApp reservation trigger.
-   **Smooth Interactions**: Elegant animations and transitions for a premium user experience.

## 🛠️ Tech Stack

-   **Frontend**: React.js
-   **Build Tool**: Vite
-   **Styling**: Vanilla CSS (CSS3 Variables & Grid/Flexbox)
-   **Icons**: Lucide React
-   **Typography**: Inter & Playfair Display (Google Fonts)

## 🚀 Getting Started

### Prerequisites

-   Node.js (v18 or higher recommended)
-   npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
